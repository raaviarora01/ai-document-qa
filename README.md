# AI Document Q&A System

A production-oriented AI Document Q&A application that allows users to upload PDF documents and ask natural-language questions about their content using Retrieval-Augmented Generation (RAG).

## Planned Tech Stack

- **Backend:** Java 21, Spring Boot
- **Database:** PostgreSQL
- **AI:** Gemini
- **Vector Database:** Qdrant
- **Document Processing:** Apache PDFBox
- **Security:** Spring Security, JWT
- **Testing:** JUnit, Mockito, RestAssured, Playwright
- **Frontend:** React
- **Deployment:** Docker, AWS
- **CI/CD:** GitHub Actions
